# Generated API provenance

`manifest.json` records the exact Authara Core commit and OpenAPI contract hash
used to create `authara/openapi_types.gen.go` and
`authara/openapi_client.gen.go`. The same workflow copies the access-token
revocation key contract for drift tests.

The files are updated by `.github/workflows/sync-core.yaml`. Do not edit the
generated Go files directly; update the Core contract or the Go SDK generator.
